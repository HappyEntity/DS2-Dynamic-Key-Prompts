Dynamic Key Prompts - alternative loader (xinput1_3.dll)
=========================================================

Use this only if another mod already needs dinput8.dll in the game folder.

1. Install the main Dynamic Key Prompts files as usual, but do NOT copy its dinput8.dll
   (or delete it if you already did, unless it belongs to your other mod).
2. Copy xinput1_3.dll from this archive into the Game folder, next to DarkSoulsII.exe.

The mod works exactly the same with either loader. If both are present, only one of them
starts the mod.

Not compatible with other mods that also ship an xinput1_3.dll.
